# Thai Top 500 Audio Game

Audio-first browser game to hear, understand, and master the top 500 most common Thai words (from the Thai National Corpus).

## Features
- Flashcards with self-rating
- Hear & Choose quizzes (shows correct answer on miss)
- Romanization for many words
- Progress tracking (localStorage)
- Export progress JSON
- Dashboard

## Local use
Open `index.html` in a browser (needs to be served, or use a simple local server because it fetches `words.json`).

## Hosting
Designed for GitHub Pages. Once the repo is public and Pages is enabled on the `main` branch / root, it will be live.
